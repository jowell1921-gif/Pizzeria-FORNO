# 0014 — Cierre de la web y preparación para Flutter (Fase 12)

Fecha: 2026-11-12

| Tema                                                       | Decisión                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Contrato                                                   | `docs/api/openapi.json`, generado por código (`npm run docs:openapi`) y **siempre sincronizado** (una prueba falla si el archivo guardado difiere del que genera el servidor). Cada operación tiene un `operationId` estable (`getProducts`, `postOrdersByIdCancel`…) para que los generadores de clientes (Dart) produzcan métodos con nombres legibles                                                                                                                                                                                                                                                                                                                                                        |
| Pruebas de consumo de la API (decisión 12 del propietario) | **Cliente independiente** (`backend/tests/consumer/`): no importa código del servidor; lee solo el contrato publicado, llama por HTTP a la API real con PostgreSQL y valida cada petición y respuesta (estados, cuerpos y errores) con Ajv contra los esquemas. Recorre el viaje de la app: carta pública, errores y renovación de sesión tras un 401, perfil y direcciones, pedido en efectivo con reintento idempotente, pago con tarjeta, ticket PDF y factura, puntos y canjes, asistente. Cubre todas las operaciones de la app. Se eligió esto en lugar de un cliente Dart porque no obliga a instalar Flutter, corre en la integración continua y detecta cualquier desviación entre servidor y contrato |
| Ejemplos                                                   | `docs/flutter/ejemplos.md` se genera con las respuestas **reales** de ese mismo viaje (`UPDATE_EXAMPLES=1`), así que no pueden inventarse                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Errores                                                    | `docs/flutter/errores.md` lista todos los códigos con la acción recomendada para la app; una prueba escanea el código y falla si falta o sobra algún código                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Diagrama de la base de datos                               | `docs/database/diagrama.md` (Mermaid), generado desde `schema.prisma` (`npm run docs:schema`) y comprobado por una prueba                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Reglas de negocio                                          | Centralizadas en el backend y descritas en `docs/flutter/reglas-de-negocio.md`: la app no reimplementa ninguna                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Versionado de la API                                       | `/api/v1` solo recibe cambios compatibles (añadir campos, operaciones o valores); un cambio incompatible saldría como `/api/v2` con aviso previo. La app debe ignorar campos desconocidos y tener un caso por defecto para estados y códigos nuevos                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Pagos y sesión en la app                                   | Sin SDK de Stripe en la app: se abre la URL de Stripe Checkout en el navegador y se consulta el pedido hasta que el servidor confirme el pago. La sesión la gestiona `supabase_flutter`; la app reintenta una vez tras `TOKEN_EXPIRED`                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Dependencias nuevas                                        | `ajv` y `ajv-formats` (solo desarrollo, para validar contra el contrato)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
